# 水まわりサポート あおぞら — 広告用LP Sample

架空の水道修理業者を想定した、リスティング広告（検索広告）用ランディングページのコーディングサンプルです。
会社名・電話番号・料金・修理事例・お客様の声などはすべて架空のものです。

## 使用技術

- HTML5（WAI-ARIA）
- Sass（SCSS）… 設定・ベース・共通パーツ・セクションごとにファイル分割、BEM命名
- JavaScript（バニラJS、ライブラリ不使用）

## 実装内容

- スマートフォン優先の設計（広告からの流入の大半がスマホのため）
- ファーストビューに「到着時間・料金・電話/WEBボタン」をまとめ、スクロールなしで問い合わせできる構成
- スマートフォン用の追従ボタン（電話・WEB）
  - ファーストビューを過ぎてから表示し、フォーム表示中は隠す
- ヘッダーに現在時刻つきの受付状況を表示
- よくある質問のアコーディオン（`aria-expanded` / `hidden` で開閉状態を伝える）
- 問い合わせフォームの入力チェック（未入力・電話番号の桁数）、エラー表示と完了表示
- スクロールに合わせたフェードイン（JSが無効な環境では最初から表示）
- 見出しの文節改行（`word-break: auto-phrase`）
- `prefers-reduced-motion` への配慮

※サンプルのため、電話ボタンはフォームへ移動し、フォームの内容は送信されません。

## Sassのコンパイル

```bash
npm install
npx sass scss/style.scss css/style.css --style=expanded --no-source-map
```
